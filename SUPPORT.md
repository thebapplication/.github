# Support

## Engineering

- Bugs and feature requests: open an issue in the relevant repository using the
  provided forms.
- Questions about a change: comment on the related pull request or issue.
- Internal discussion: the team channel for the repository.

## Product and customers

Customer-facing support requests are handled through the product support channel,
not GitHub issues.

## Security

Security vulnerabilities follow [SECURITY.md](SECURITY.md). Do not report them in
public issues.

## Response times

Issues are triaged on the next working day. Priority follows severity and
customer impact.
