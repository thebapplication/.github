# Security Policy

## Supported versions

Only the version currently deployed to production is supported. Fixes are applied
to `main` and released forward.

## Reporting a vulnerability

Do not open a public issue or pull request for security matters.

Report through one of the following channels:

- GitHub private vulnerability reporting on the affected repository
  (`Security` tab, `Report a vulnerability`).
- Email [devteam@weareb.co](mailto:devteam@weareb.co).

Include:

- Affected repository, environment, and version or commit.
- A description of the issue and its impact.
- Steps to reproduce or proof of concept.
- Any known mitigations.

## Process

- Acknowledgement within 3 business days.
- Assessment and severity rating within 10 business days.
- Progress updates at least every 10 business days until resolution.
- Coordinated disclosure after a fix is deployed. Credit is given on request.

## Scope

In scope: source code and infrastructure configuration in this organisation, and
the services they deploy.

Out of scope: findings that require physical access, social engineering, or
denial-of-service testing against production systems.
